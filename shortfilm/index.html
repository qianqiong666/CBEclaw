01

两条经营线：授权批量做现金流，原创精品做资产

不再按4账号的小型原创工作室规划。按公司的至少10个账号、每日50条合格成片目标组织，但不把产量、播放和到账当成同一件事。

快线 / 授权经营

批量译制＋分销/发行

已有海外授权的剧集，批量完成转录、翻译、配音、字幕与剪辑，接入实际可结算的CPS、机构发行分账或付费译制订单。成熟模块直接压测，不必人为限制每天只做几条。

先明确是推广片段权还是全片发行权。目标50条合格成片/日，收入须以对应合同、有效转化和结算为依据。

长线 / 原创IP

有短剧经验的主创做精品

编导、AI创作师和剧情后期负责3–20分钟的故事、角色、镜头与声音。单独排产和核算，不背每天50部新原创的指标，不被批量翻译质检占满。

现有技术组提供制作工具。这仍是内容团队，不招聘短剧播放平台开发者。

建议决策：大陆公司先推进真实企业合作与对公收款；香港主体按长期自营需求评估，不为TK中视频奖励盲目注册。首批10账号＝授权经营8个＋原创品牌2个。

必须分开验证的四件事

有权发行 → 计划准入 → 作品可计费 → 银行到账。有版权不等于获原创奖励；有香港公司不等于符合海外个人资格；银行能收美元不等于已经加入YPP。

不要误用“素材任务”资格

星图素材任务支持制作后交付、无需达人发布，但本轮官方文档注明首期开通条件为明星达人或至少500万粉丝等限定，并非新公司通用零门槛入口。

尚未符合时，可与现有品牌客户合规直签制作合同；能接单仍需真实客户，不虚构订单。

[29]

把“作品”和“广告”分开核算

原创短片负责建立叙事能力与品牌辨识度；商业项目负责验证可收费交付；商品广告负责验证成交。

原片不强行插入不相关商品。另开品牌命题或商品场景广告，把同一套角色一致性、分镜和剪辑能力复用过去。观众共鸣、客户付费和投放ROI分别验收。

报价示例只是算术：若完整交付成本8,000元，目标项目毛利率40%，报价参考为8,000÷(1−40%)≈13,333元，而不是加40%得到11,200元。先确定成本是否含税、返修、授权和人员分摊；这不是市场成交价，毛利也不是最终净利。

本月两项原创立项练习（新设定草案，不是保证爆款）

《谢谢额度》

城市每说一次感谢就会消耗额度。主角为最重要的关系保留最后一次，最终发现真正有分量的是行动。先写出具体事件和代价，避免只做概念金句。

《默认答案》

生活助手总能给出最省事的选择，却逐渐替主角跳过所有可能改变关系的决定。用一个实际冲突推进，不复制外星交易的场景或台词。

实际制作前继续查重、审查权利与受众适配。每个方向先交一句话故事、完整大纲和30秒预演，通过才生成正式镜头。

04

大陆公司还是香港公司？先看谁给你付款

“TK中视频”在本页指Creator Rewards，不是国内西瓜/抖音中视频伙伴计划。公司为主要经营和资产主体；个人港卡不等于香港公司银行账户。

结论一 / TK中视频奖励

不能靠注册公司解决

这是符合条件的个人类型账户的创作者奖励，不是拿营业执照直接参加的企业计划。大陆公司和香港公司都不能替代个人、地区与原创资格。

[33][9]
结论二 / TK短剧发行与CPS

先以大陆公司核验

直接机构合作要看平台合同；第三方分销要看付款公司。没有证据表明所有短剧分账都必须香港公司，也没有公开证据保证本公司一定可直接收。

[8][35]
结论三 / YouTube

大陆有付款渠道，准入另审

Google的中国YouTube付款表列有电汇；组织账户按公司名付款。收款不一律需要香港公司，但大陆不在当前YPP新申请地区名单。

[31][5][2]
实际收入大陆公司对公香港公司要做的动作
TikTok Creator Rewards不能按企业报名/企业账户即享奖励的方式办理。不能代替合格个人及所在地。没有真实合格创作者与对应支付资格时，不把它列为公司保底。
TikTok Drama Center机构合作本公司准入、大陆银行支持，仍需正式答复。是否需要取决于具体合作和支付规则，不先假设必须。先提交大陆公司资料，书面问主体、受益人、币种和账期。
发行商CPS、译制费、版权费对方接受大陆公司签约且开户行接受真实交易来款时，按对公合同办理。通常不因流量来自TK或YT就必需；看合同与渠道。确认实际付款法人、授权范围、有效订单和扣回规则。
YouTube付款中国地区有官方电汇支持；已获批中国组织付款资料按规则配置银行。香港资料用匹配的银行，可作为真实境外经营配置。先核验组织AdSense、付款地区、名称、银行与税务。
YouTube新申请YPP这是地区/内容准入，不是银行卡问题。中国大陆不在当前名单。香港在名单中，但注册证和IP不是获批保证。实际经营结构、所在地和身份须符合平台要求，不能虚报。
不要把两张官方表混在一起：中国地区支持YouTube电汇，说明有支付渠道；YPP开放地区不含中国大陆，说明新申请另有资格限制。付款表不是大陆新频道必过的证明，地区表也不是“中国银行一概收不到钱”的证明。

1. YouTube企业收款怎么配置

真实合格的经营/收益主体 → 组织AdSense for YouTube → 公司名称付款资料 → 地区匹配的企业银行 → 财务对账。

Google明确：组织款项付给公司名称；电汇银行地区需与付款资料地区一致。建议使用公司同名对公账户，香港资料不混绑大陆卡，大陆资料也不随意混绑香港账户。向银行核对受益人英文名称、SWIFT、币种和来款凭证。

多个频道可以使用同一个AdSense for YouTube。同一收款人不要创建多个重复账户；每个频道仍单独达到YPP条件。10个内容账号不等于10套公司或收款账户。

个人AdSense不能直接切换账户类型为组织，应按平台正式迁移/关闭重建等指引处理。不要把第三方账户借给公司使用。

[5][6][32]

2. TK中视频奖励：不是国内卡与香港卡二选一

TikTok官方项目介绍要求可用地区的个人类型账户，并强调原创；2026年Organization功能清单仍将Creator Rewards列为不可用。公司可做制作与运营，但不因此获得个人奖励的申请资格。

具体地区支持的支付服务、收款人身份、税务资料及是否接受某类钱包，应以该市场当前条款和实际收益后台为准。本轮官方英语付款帮助页抓取受限，不承诺大陆企业银行、香港企业银行或某个公司PayPal一定能绑。

真实合格创作者与公司之间的版权、劳务或收益分配，另按实际关系签约和纳税，不能借名或购买收益号来替代资格。

[33][9]

3. TK短剧收入：平台分账和第三方佣金要分开

Drama Center：官网确认短剧机构发行、翻译、发布、广告分成及付费解锁等合作方向，但未公开足以保证本公司/银行被接受的清单。先用大陆公司核验，不替平台承诺。

CPS/发行合同：观众在TK看到推广，不代表TikTok付款；实际可能由版权方或发行商支付有效订单佣金。看合同付款法人和银行接收要求。推广授权不自动包含整剧重配音、翻译或全片发行。

RS Boost是官方CPS机制实例，其协议对重配音等改动有额外同意要求；不能把默认推广素材许可当作任意译制许可证。

[8][35]
针对公司的建议：现在先走大陆公司可获准的企业合同和收款路径。长期明确自营海外版权/YouTube，且平台与银行接受真实经营结构时，香港公司＋企业账户可以成为统一的境外业务主体；它的价值是规范经营和结算，不是绕过Creator Rewards或YPP规则。
决定注册香港公司前，确认这5项
  1. 实际做哪个收益计划、由哪家法律主体付款。
  2. 平台是否接受拟议的真实主体、地址、运营安排与授权。
  3. 企业银行开户及该类来款能否通过审查。
  4. 秘书、地址、周年申报、会计/审计及税务等持续安排。
  5. 与大陆制作公司的版权、服务及资金往来如何记账。

不是办好公司即可免税、自动获批或随意使用虚拟银行。法律、银行和税务事项由相关专业人员按实际结构确认。

06

批量译制是经营能力，原创精品是长期能力

允许技术提高授权内容的产能，但先确认哪种作品和结果可以结算。

授权经营生产线

  1. 核验海外地域/语言/平台、翻译配音及商用权利，区分推广片段与完整剧集。
  2. 取得母版、原剧本/字幕和音轨，建立授权ID与期限。
  3. 批量转录、术语统一、语境翻译、配音字幕及合成。
  4. 技术QC、语言和内容审核，按批准语种/品牌排期。
  5. 对应交付单或推广链接，跟踪有效转化、结算、成本。

已有成熟流水线可直接做目标压力测试，不以人工小样限制技术产能；未经质检的输出不算合格成片。

原创精品生产线

  1. 编导确定故事、人物目标、冲突与结局。
  2. 分镜和声音预演通过，再调用昂贵生成。
  3. AI创作负责连续镜头、角色一致性和表演。
  4. 剧情后期负责节奏、混音和最终完成度。
  5. 复盘观众、成本与真实商业机会，沉淀角色与方法。

内容人才不开发平台；技术组为制作提供工具。

去重的正确用途：内部重复文件/任务检查、素材归并、语言版本管理、误发和重复扣费预防。对外内容用真实本地化与创作价值获得观众，不以镜像、裁切或变速躲避审核。
有许可≠一定获原创奖励。YouTube明确二次利用审核独立于版权许可；批量同质内容也可能不适合创收。TikTok Creator Rewards强调原创。技术改变文件特征，不等于改变作者身份或收益资格。[4][33]

短期收入按优先级核验

自营频道：同时积累，但只有资格与内容获准后才核算广告收益。

这是经营建议，不代表已拿到上述合作或保证快钱。哪条已有真实客户和合同，哪条先验证；没有合同就不把制作量等同应收收入。

用合同收入公式决定扩量

净贡献＝确认净收入－完整制作成本－投流－退款/扣回－其他约定费用。

假设50条/日、完整制作成本20元/条，即1,000元/日；30个生产日共3万元。再假设每个有效转化净结算10元，每天100个有效转化只覆盖制作成本，广告等未计入时还不是净利润。

20元与10元是演示假设，不是报价。版权、人工、生成失败、翻译审校、算力/软件和存储分摊计入完整成本；不要用自己消耗时间未计价制造高利润。

已经能批量制作，可以同步经营，不必只等原创精品。但首笔平台/发行商结算应尽早验证；账期未到记应收，不记到账。单纯追求去重成功和播放截图，不等于商业验证。
