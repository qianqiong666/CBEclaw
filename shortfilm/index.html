01

先做内容生产与经营，不先自建短剧App

执行建议：先一门主语言、两条内容路线；技术共用，权利、成本、审核与回款分别记录。

路线A · 流程验证

授权本地化

自有版权或取得海外许可的国内作品，做翻译、配音与文化适配。目标是验证发行和生产流程，不把去水印、镜像、变速当作获得版权。

路线B · 长期资产

原创精品

先做3–5分钟、少角色少场景的完整故事，跑通叙事、镜头一致性与成本，再扩到8–20分钟。不要先全自动生产几十集再找受众。

首月目标不是靠播放奖励覆盖投入。先取得权利与主体可行性，做出样片、统一流程并建立观众/客户反馈。授权不等于平台创收审核通过。[4]

保留三条不同收入线

商业制作与授权：有合同和验收的订单。
自有IP与频道：积累可持续的观众与作品。
公司已有电商：测试原创剧情广告的净成交与素材效率。

三条线共用制作资产，但分别核算。不要把一个泛情绪爆款的播放量直接算成商品销量或软件付费。

陌生设定

用不合常理的交易制造疑问，先让观众想知道规则。

熟悉困境

具体人物面对责任、时间与选择，观众可以代入自己。

规则产生后果

设定改变生活，而不是只用旁白宣讲一个观点。

把问题留给观众

有讨论空间，可能引发转发；不等于保证算法推荐。

可借鉴的是制作方法，不是照搬故事。主创先写核心问题和剧本，再稳定角色、场景、道具与机位，最后生成和后期。对公司而言应沉淀参考资产、镜头工单、版本和质检，而不是只采购更多算力。[25]

03

对公司来说，怎样把好片变成生意

以下为商业建议，不是该作者已经实现的收入明细。

收入路径谁付钱 / 为什么成立条件首期优先
品牌原创短片品牌为创意、制作和约定的使用权付费有样片、客户、合同、授权范围与验收高：从已有商家需求测
自有账号商单品牌为创作与账号传播购买服务受众匹配、账号资质、商业规则和实际履约中：先证明内容和受众
平台奖励/比赛平台按具体计划、资格和作品表现结算计划准入、内容达标；奖金须实际确认补充，不进保底收入
IP/海外授权发行商或买方为地域、语言、平台等权利付费权利链清楚，合同明确分成/保底/期限中：取得合适片库再谈
自营商品剧情广告消费者购买真实商品，公司赚商品净利润产品匹配、效果真实，扣完投流/退款/履约高：最能复用现有团队
自有工具/工作流创作者购买已验证的软件能力或服务权属、可复用性、客服与实际付费需求后置：独立验证，不能把观众当购买者

已核实的对公商业入口

巨量星图官方有企业达人对公结算流程：按任务与结算单完成手续，款项进入登记的对公银行账户。它是商单结算，不是“每个点赞付多少钱”。

还需实际开通、符合任务资格、合同归档和开票。具体税务、票据及账期按后台和财务核定。

[28]

不要误用“素材任务”资格

星图素材任务支持制作后交付、无需达人发布，但本轮官方文档注明首期开通条件为明星达人或至少500万粉丝等限定，并非新公司通用零门槛入口。

尚未符合时，可与现有品牌客户合规直签制作合同；能接单仍需真实客户，不虚构订单。

[29]

把“作品”和“广告”分开核算

原创短片负责建立叙事能力与品牌辨识度；商业项目负责验证可收费交付；商品广告负责验证成交。

原片不强行插入不相关商品。另开品牌命题或商品场景广告，把同一套角色一致性、分镜和剪辑能力复用过去。观众共鸣、客户付费和投放ROI分别验收。

报价示例只是算术：若完整交付成本8,000元，目标项目毛利率40%，报价参考为8,000÷(1−40%)≈13,333元，而不是加40%得到11,200元。先确定成本是否含税、返修、授权和人员分摊；这不是市场成交价，毛利也不是最终净利。

本月两项原创立项练习（新设定草案，不是保证爆款）

《谢谢额度》

城市每说一次感谢就会消耗额度。主角为最重要的关系保留最后一次，最终发现真正有分量的是行动。先写出具体事件和代价，避免只做概念金句。

《默认答案》

生活助手总能给出最省事的选择，却逐渐替主角跳过所有可能改变关系的决定。用一个实际冲突推进，不复制外星交易的场景或台词。

实际制作前继续查重、审查权利与受众适配。每个方向先交一句话故事、完整大纲和30秒预演，通过才生成正式镜头。

04

主体、资质与公司收款

香港公司可评估，不是所有业务必需，更不是换IP就获得收益资格。

当前YPP地区名单包含香港、不含中国大陆；还需满足所在地及其他要求。香港主体只是可评估的真实经营路径，不保证由大陆团队运营即可获批。[1][2]

大陆公司制作 / 授权

向合格海外发行方交付或授权，按真实合同对公结算。先核地域、语言、平台、独家、数据、账期与退出；不要借用员工个人奖励账户当公司长期收款方案。

真实境外企业自营

先问清平台接受的实际经营结构、银行与税务，再考虑香港或其他合格主体。注册、秘书、地址、年度申报、会计和账户维护均有持续成本，不只看注册费。

[21]

收款链保持可核验

内容权利方 → 合格经营企业 → 平台/发行合同 → 企业银行 → 财务对账。

AdSense组织账户按公司名称付款；银行地区、付款资料、受益人和币种按平台规则核验。按真实身份提交税务资料，美国来源收入可能被预扣。不要认为香港公司就免税。

[5][6][7]

国内生产与海外播出也需要核定许可

制作、授权分销、自建平台的资质不同。《微短剧发展管理办法》自2026年9月1日施行，涉及分类备案、审核和AI标识等，包含境内拍摄用于境外播出的情形。独立短片/全AI作品如何归类，向广西主管部门和播出平台核定。

本页不是法律意见；不将每个短视频机械视为相同许可，也不默认海外播出豁免。

[16]

06

两条生产线，共用一套底座

A / 授权本地化

  1. 取得海外平台/语言/变现权，无硬字幕母版、原剧本和分轨。
  2. 文化适配、翻译、人工英语审校。
  3. 配音字幕混音；声音克隆另核授权。
  4. 封面、标题、预告与版本记录。
  5. 审核后发布，追踪认领、反馈和结算。

B / 原创精品

  1. 核心问题、人物动机、完整故事。
  2. 分镜与声音预演先通过。
  3. 人物/场景/道具参考资产统一。
  4. 逐镜头生成、合成、技术与内容QC。
  5. 局部重做、正片与少量衍生发布。

授权与原创审核分别管理

授权需覆盖作品、语言/地域/平台、翻译剪辑配音、商用、期限、独家/分授权、音乐/肖像/声音、Content ID和投诉处理。国内分销权不自动含海外全片发行。

AI可以参与创收内容，但批量重复、缺少原创贡献仍有风险；逼真合成内容按适用规则披露。没有授权的二创不能靠调色、变速或镜像变合法。

一个负责作品质量，一个负责系统稳定。现有技术组共用，不因新增海外方向再搭五端App团队。

首期技术招聘不变成App研发

当前更需要AI应用全栈与Python视频工作流：数据库、队列、素材、FFmpeg、API、错误恢复。AI全栈骨干仍可从12–16K议价，视频工作流9–13K；均为建议，能力强再谈。

6–8K怎样用得合理

可测试有项目能力的初中级应用/工具开发候选人，职责收窄为内部页面、接口、报表、脚本和测试，有骨干审代码。不能仅凭年限或价格预判能力，也不能承诺独自扛五端。

可复制的短剧技术岗位文案
岗位：AI应用开发工程师（短剧制作工具 / 工作流） 工作地：南宁五象，现场协作。 负责：素材库和任务看板、授权API对接、批量视频处理、失败恢复、版本/成本/审核记录、部署测试与文档。 要求：Python或Node.js等一门语言能独立排错；懂Git、SQL、HTTP；熟练使用AI编程并能解释代码；有可演示项目。 加分：FFmpeg、字幕/音轨处理、异步队列、电商/视频系统经验。 边界：首期不要求独立开发Android+iOS+Web全平台，不操作未经批准的真实广告预算。 薪资：按承担的模块与工程责任评估，不仅按“会不会用AI”定级。

首月：内容验证与客户验证同时进行

阶段制作/技术经营/发行验收
第1周授权与资产盘点、两路线选题、角色/分镜规范主体/收款预核验；向3–5家熟悉商家收集真实内容需求（建议）预算、责任人与权利明确
第2周A交2个本地化样本；B交剧本和30秒预演确认品牌需求、交付范围和可用收款途径预演、英语与成本过审
第3周A累计4–6；B首部3–5分钟与短预告合规发布；争取小额付费试单，不免费无限改稿作品反馈与客户反馈分开
第4周质量允许再做第2部，沉淀可复用流程查看实际订单/回款、观众数据，决定继续/调整/停不以单条爆款或未到账收入扩编

内容线考核

故事清晰度、留存/点击/回访、评论内容、合格片成本和人工重做时长。不同长度、平台、自然/付费来源分组比较，不编造统一及格线。

商业线考核

有效需求、报价接受、付费订单、返修工时、项目毛利和实际回款。没有真实付费时先修产品与客户匹配，不靠预计流量证明盈利。
