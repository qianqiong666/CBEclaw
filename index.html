01

招聘策略：2 名核心先到岗

不再机械照搬之前“15–20K + 10–15K + 8–12K”的三成熟岗配置；根据新截图和本地岗位，调整为按能力与阶段招聘。

推荐 · 成本与培养兼顾

方案 A · 2 位骨干＋1 位新人

主程 12–16K ＋ 视频 9–13K；运转稳定后补 AI 编程应届生 5–7K。

26–36K /月税前工资
适用：现阶段最缺工程稳定性、素材流程开发；主程有时间带新人。
备选 · API 接口需求极重

方案 B · 3 位成熟开发者

主程 12–16K ＋ 视频 9–13K ＋ 业务API集成 8–12K。

29–41K /月税前工资
适用：已经积压真实平台API、数据同步、投流对接，不具备带新人条件。

我的具体建议：本月先发布“AI 应用全栈工程师”“Python 视频工作流工程师”。两位骨干能稳定交付后，补一位 AI 编程毕业生。若投流 API 成为真正瓶颈，就把第三个名额换成有经验的 API 集成开发。

02

岗位定义与对外招聘文案

薪酬均为建议的 税前固定月薪；具体社保公积金、单双休、奖金和办公地址由公司确定后填写。不要用未落实的福利吸引候选人。

P0 · FIRST HIRE / 1人

AI 应用全栈工程师（任务系统／后端）

南宁五象 · 现场协作 · 真实业务系统
12–16K能力很强可谈15–18K
不是招模型训练岗：要能把 AI Coding 生成的代码变成可维护、可运行的生产系统。

主要负责

  • 统一商品、视频素材、账号、任务和执行记录；建立数据库/API。
  • 异步队列、失败恢复、重复任务控制、日志与权限。
  • Windows/Mac 执行端的任务下发、部署、监控与版本回退。

招聘门槛

  • Python／Node.js／Java 至少一门能独立排错；懂 SQL、Git、接口与部署。
  • 熟练使用 Codex／Claude Code 类工具，但能读懂、测试和维护代码。
  • 有真实上线案例，能讲清自己踩过的线上问题。
验收题：20个异步任务、429、超时与重启恢复。
P0 · PARALLEL HIRE / 1人

Python 视频自动化工程师（FFmpeg／AIGC）

电商视频 · 漫剧授权切片 · AI 短剧样片
9–13K成熟案例可上调
核心目标是让视频工作流“断点可续、失败可查、结果可验”，不是只会点 AI 出片。

主要负责

  • 素材入库、转录、切镜头、字幕、配音、合成、规格导出。
  • 对接视频/图片/语音 API，处理队列、限流、预算和任务有效期。
  • 把有效流程做成 Skill、CLI 或服务接口并连接共享底座。

招聘门槛

  • Python + FFmpeg/ffprobe，能调试文件、音轨、时间戳问题。
  • 有可展示的视频批量处理流程；能解释局部重做。
  • 理解API及基本数据结构；ComfyUI/镜头分析加分。
验收题：3段样片合成双规格；中断后只补失败项。
P1 · THIRD HIRE / 1人

AI 编程／全栈开发助理（应届生可投）

有主程带 · 小模块开发 · 自动化测试
5–7K独立交付者可再定级
能招聘，但必须建立在有骨干审代码、带设计、把关上线的条件上。

主要负责

  • 内部工具页面、轻量 API、数据清洗、小型 Skill 和脚本。
  • 录制复现问题、编写回归测试、整理部署说明与素材规范。
  • 在真实项目里使用 Codex 等工具，先修小缺陷再接复杂模块。

招聘门槛

  • 至少一个自己能演示、能解释架构和错误处理的项目。
  • 掌握基本 Git、HTTP、数据库、前后端知识；愿意做测试与文档。
  • 允许用 AI，但不能不看代码直接上线。
验收题：完整运行现成项目、修 Bug、加一个 API/小页面及测试。
P1 · ALTERNATIVE THIRD HIRE / 1人

业务自动化工程师（API／数据集成）

当投流和跨平台接口成为主要瓶颈时优先
8–12K有经验的联调工程师
把商品、视频、广告计划和业务报表连起来；先只读、再审批，最后自动执行。

主要负责

  • 授权平台 API、鉴权、分页、限流、字段同步与日志。
  • 素材 ID、广告计划 ID、商品 ID 的统一映射和数据回传。
  • 构建待审批操作与异常报警，减少在真实广告账户上的试错。

招聘门槛

  • 至少一门后端语言、SQL、第三方 API 接入与错误定位。
  • 有电商、广告、ERP、支付或类似接口联调经验优先。
  • 能解释成本归因和权限边界，不用灰色绕过式自动化。
验收题：模拟订单/广告API，同步去重并生成待审批操作。
03

要不要招会 AI 编程的应届生？

结论：值得招一位，但不是拿他替代主程。毕业生的价值是便宜、学习快、能持续做小模块、测试与文档。培养以后可以承担更多 Skills 和内部工具；但生产数据库、投流预算、并发任务与客户交付，必须有成熟工程师把关。

适合现在招 ✓

已经有一位能审代码的主程；团队有明确需求池、现成仓库、测试环境；能安排每周固定代码 Review 和阶段反馈。

不适合马上招 ×

只有你自己能处理所有技术问题；要新人第一天独立上线广告自动投放；需求频繁变动、没有代码仓库和日志。

01

面试看作品，不看证书

允许当场使用AI，要求解释代码、排查错误、说明测试和重试边界。

02

前2周先上手

修复小问题、写脚本、补接口单测、改内部页面，按周 Review。

03

第6–8周再交小模块

通过审查后承担完整小流程；连续交付过关再谈提薪和权限。

薪资依据：广西人才网2026年二季度毕业生 IT 岗招聘平均约4,725元/月、求职期望平均约6,674元/月；因此给真正有项目能力的新人开 5–7K 是较合理的测试带宽，不是所有应届生统一7K。 原报告 ↗

05

招聘筛选：允许用AI，但必须会排错

01

15分钟初筛

能到五象吗？为什么想做生产系统？演示自己做过的项目与AI开发工作流。

02

30–45分钟技术复盘

从上线、失败、数据库、权限、成本和调试中挑真实问题，要求说出本人贡献。

03

2小时有偿实操

提供模拟接口与脱敏素材。新人修bug＋补测试；成熟岗考任务恢复、视频合成或API去重。

五项打分（总分100）

实际完成与结果验收30分
失败恢复、重复操作与成本意识25分
代码、数据结构与安全性20分
解释思路与团队沟通15分
AI编程效率与学习能力10分
06

90天：别同时开发六套孤立系统

DAYS 01—30

跑通一条电商链

选一个已有货盘，打通素材入库、生成任务、审核与导出；保留人工回退。

验收：实际运行记录、失败恢复、单位合格内容成本
DAYS 31—60

连接数据与漫剧样片

经授权接入投流数据；将底座复用到一条正版漫剧分销链或AI短剧样片。

验收：素材ID和投放计划关联，成本与版本可追溯
DAYS 61—90

复制有效流程

扩大到其他品类或平台，再根据真实瓶颈决定补 API 人才还是测试实施岗。

验收：人员使用、故障率、人工处理时间和实际业务反馈
